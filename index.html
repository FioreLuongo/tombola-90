Come Mettere il Progetto in Rete (100% Gratis)

Configurazione passo-passo per Render, Cloudflare Pages, Firebase Hosting e Vercel con Database Cloud

FASE PRELIMINARE: Inviare il Codice su GitHub (Passo Comune)

Prima di collegare qualsiasi servizio di hosting, carica il codice nella tua repository GitHub:

  1. Crea una nuova repository pubblica su github.com/new con nome tombola-90.
  2. Apri il terminale nel tuo computer nella cartella del progetto (oppure estrai lo ZIP scaricato) ed esegui:
git add .
git commit -m "Tombola 90 Gold Edition"
git branch -M main
git remote add origin https://github.com/TUO-USERNAME/tombola-90.git
git push -u origin main

1. CONFIGURAZIONE PASSO-PASSO AD HOC SU RENDER (100% Gratis & No-Sleep)

Vantaggio: I "Static Sites" su Render non vanno mai in sleep e sono gratis per sempre!

I file di configurazione sono già pronti nel tuo progetto: il file render.yaml nella radice definisce la compilazione con Vite e i redirect per la Single Page Application.

1
Vai su render.com e accedi tramite il pulsante "GitHub".
2
Nella Dashboard di Render, clicca in alto a destra su + New ➔ seleziona "Static Site".
3
Clicca su "Connect" accanto al tuo repository tombola-90.
4
Compila i parametri richiesti (quasi tutti rilevati in automatico):
  • Name: tombola-90
  • Branch: main
  • Root Directory: (lascia vuoto)
  • Build Command: npm run build
  • Publish Directory: dist
5
Verifica Rewrite SPA: in basso nella sezione Advanced ➔ Redirects/Rewrites, grazie a render.yaml troverai già configurato:
Source: /* ➔ Destination: /index.html (Action: Rewrite).
6
Clicca sul pulsante "Create Static Site". In circa 60 secondi il sito sarà online su:
https://tombola-90.onrender.com

2. ALTERNATIVA TOP: CLOUDFLARE PAGES (Velocità Record & Traffico Illimitato)

Cloudflare Pages è tra le piattaforme più veloci e performanti al mondo, con CDN globale e banda illimitata gratuita.

  1. Accedi su dash.cloudflare.com (crea un account gratuito in 30 secondi).
  2. Nel menu laterale clicca su Workers & Pages ➔ scheda in alto Pages ➔ "Connect to Git".
  3. Seleziona la repository tombola-90 e clicca su "Begin setup".
  4. Imposta:
    • Framework preset: Vite
    • Build command: npm run build
    • Build output directory: dist
  5. Clicca "Save and Deploy" (il file public/_redirects è già incluso nel progetto per gestire i reindirizzamenti).
  6. Il sito sarà subito attivo su: https://tombola-90.pages.dev

3. ALTERNATIVA NATIVA: GOOGLE FIREBASE HOSTING

Dato che il database Firestore si trova già sul progetto Firebase agile-lamp-6xq1s, puoi pubblicare il sito direttamente sui server di Google senza dover autorizzare nessun dominio esterno!

Il file firebase.json è già predisposto nel progetto. Dal tuo terminale:

npm install -g firebase-tools
firebase login
npm run build
firebase deploy --only hosting

Il sito sarà subito live su: https://agile-lamp-6xq1s.web.app

4. ALTERNATIVA VERCEL

Anche Vercel è supportato nativamente grazie al file vercel.json già configurato:

  1. Vai su vercel.com e fai login con GitHub.
  2. Clicca su "Add New..." ➔ "Project".
  3. Fai Import della repository tombola-90 e clicca Deploy. Il sito sarà attivo su https://tombola-90.vercel.app.
FASE FINALE OBBLIGATORIA: Abilitare il Dominio nella Console Firebase

Se hai scelto Render, Cloudflare o Vercel, ricordati di autorizzare il dominio su Firebase per consentire la sincronizzazione del Montepremi Cloud:

  1. Apri la Console Firebase sul progetto agile-lamp-6xq1s.
  2. Vai su Authentication ➔ scheda Settings ➔ Authorized domains (Domini autorizzati).
  3. Clicca su "Add domain" e incolla il tuo link (senza https://):
    • Se hai usato Render: tombola-90.onrender.com
    • Se hai usato Cloudflare: tombola-90.pages.dev
    • Se hai usato Vercel: tombola-90.vercel.app
  4. Clicca su Salva. Fine! Il tuo gioco è ora 100% operativo in rete con database cloud attivo.
